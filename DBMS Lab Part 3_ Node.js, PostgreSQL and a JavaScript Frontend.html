Part 3: Node.js, PostgreSQL and a JavaScript frontend

The same Student Records project, built the way most web companies build it: Node.js talks to the PostgreSQL database you already have, and a normal web page written in HTML and JavaScript talks to Node. Students learn both sides of a real web app.

Setup

You need Node.js 18 or newer and the PostgreSQL database and students table from the earlier parts.

  1. Check Node: node --version. Install the LTS version from nodejs.org if it is missing.
  2. Create a folder student_node, open a terminal inside it, and run: 
    npm init -y
npm install express pg dotenv
  3. express is the web server library, pg is the PostgreSQL driver, and dotenv loads settings from a file.
  4. Create the project layout. The public folder holds the web page that browsers receive:
student_node/
  .env            (database settings, never share)
  db.js           (one shared database connection)
  server.js       (the web server and API)
  public/
    index.html    (the page)
    app.js        (the page's JavaScript)

The database settings go in .env. Use the same five details as in Part 1:

PGHOST=localhost
PGPORT=5432
PGDATABASE=your_dbname
PGUSER=postgres
PGPASSWORD=your_password

Security: never upload .env to GitHub. Put the line .env inside a file named .gitignore.

JavaScript you need first

Idea Example Meaning
Variables const x = 5; let y = 1; const cannot be reassigned; use let when it changes
Arrow function const add = (a, b) => a + b; A short way to write a function
Template string `Hello ${name}` Put values inside text with backticks
async / await const r = await pool.query(...) Wait for the database without freezing the program
try / catch try { ... } catch (err) { ... } Handle errors from awaited work
fetch await fetch("/api/students") The browser asks the server for data

Database work takes time. A function that calls await must be declared async, and it returns after the database answers.

How this differs from the Python parts

Python (psycopg2) Node (pg)
Placeholders %s $1, $2, $3
Values a tuple (a, b) an array [a, b]
Saving changes call conn.commit() no commit needed; each pool.query saves on its own
Reading rows cur.fetchall() result.rows
Rows changed cur.rowcount result.rowCount
Connections open and close each time a Pool reuses connections

The SQL itself is identical. Only the placeholder style changes. Placeholders still protect against SQL injection, so never build SQL with template strings from user input.

Step 1Connect to your database

Create db.js. The pg library reads the PG... settings from .env by itself.

require("dotenv").config();
const { Pool } = require("pg");

const pool = new Pool();   // uses PGHOST, PGPORT, PGDATABASE, PGUSER, PGPASSWORD

module.exports = pool;

Create step1.js to test it:

const pool = require("./db");

async function main() {
  const result = await pool.query("SELECT version()");
  console.log(result.rows[0].version);
  await pool.end();
}

main().catch(err => {
  console.error("Failed:", err.message);
  pool.end();
});

Run node step1.js. You should see the PostgreSQL version. Fix this step before going on. pool.end() closes connections; without it a script never finishes.

Step 2Create the table

If you built the table in Part 1 you can skip this. The statement is safe to run again.

const pool = require("./db");

async function main() {
  await pool.query(`
    CREATE TABLE IF NOT EXISTS students (
      id     SERIAL PRIMARY KEY,
      name   VARCHAR(100) NOT NULL,
      branch VARCHAR(50),
      marks  INTEGER
    )`);
  console.log("Table ready");
  await pool.end();
}

main().catch(err => { console.error(err.message); pool.end(); });

Save as step2.js and run it. Check the table in pgAdmin or with \dt in psql.

Step 3Insert rows safely

const pool = require("./db");

async function main() {
  await pool.query(
    "INSERT INTO students (name, branch, marks) VALUES ($1, $2, $3)",
    ["Asha", "CSE", 82]
  );

  const more = [["Ravi", "ECE", 74], ["Meena", "CSE", 91]];
  for (const row of more) {
    await pool.query(
      "INSERT INTO students (name, branch, marks) VALUES ($1, $2, $3)", row);
  }
  console.log("Rows added");
  await pool.end();
}

main().catch(err => { console.error(err.message); pool.end(); });

Bad: `INSERT ... VALUES ('${name}')` lets a user type SQL into your program. Good: $1, $2, $3 with an array of values.

Step 4Read data with SELECT

const pool = require("./db");

async function main() {
  const all = await pool.query("SELECT id, name, branch, marks FROM students ORDER BY id");
  console.table(all.rows);

  const top = await pool.query(
    "SELECT name, marks FROM students WHERE branch = $1 AND marks > $2",
    ["CSE", 80]
  );
  console.log(top.rows);
  await pool.end();
}

main().catch(err => { console.error(err.message); pool.end(); });

Rows arrive as an array of objects, for example { id: 1, name: "Asha", branch: "CSE", marks: 82 }. This is the same shape the web page will receive later as JSON.

Step 5Update and delete

const pool = require("./db");

async function main() {
  const up = await pool.query("UPDATE students SET marks = $1 WHERE name = $2", [88, "Ravi"]);
  console.log("Rows updated:", up.rowCount);

  const del = await pool.query("DELETE FROM students WHERE id = $1", [3]);
  console.log("Rows deleted:", del.rowCount);
  await pool.end();
}

main().catch(err => { console.error(err.message); pool.end(); });

Lab check: always use a WHERE clause. An UPDATE or DELETE without one changes every row.

Step 6Your first web server

Browsers must never connect to PostgreSQL directly, because that would expose the password. The browser talks to your Node server, and only the server talks to the database. Create server.js:

const express = require("express");
const app = express();

app.get("/", (req, res) => {
  res.send("Hello from Node");
});

app.listen(3000, () => console.log("Open http://localhost:3000"));

Run node server.js and open http://localhost:3000. Stop with Ctrl+C. While developing, node --watch server.js restarts the server every time you save.

The four request types

Action HTTP method Our route SQL
Read GET /api/students SELECT
Create POST /api/students INSERT
Update PUT /api/students/:id UPDATE
Delete DELETE /api/students/:id DELETE

A set of routes like this is called a REST API. The part :id in a route is a variable that arrives as req.params.id.

Step 7Build the API

Replace the contents of server.js with the full server. Each route validates input, runs one SQL statement with placeholders, and answers in JSON.

const express = require("express");
const pool = require("./db");

const app = express();
app.use(express.json());           // read JSON sent by the browser
app.use(express.static("public")); // serve index.html and app.js

// Wrap each route so a database error returns a clean message
const handle = fn => async (req, res) => {
  try { await fn(req, res); }
  catch (err) {
    console.error(err.message);
    res.status(500).json({ error: "Database error" });
  }
};

function clean(body) {
  const name = String(body.name || "").trim();
  const branch = String(body.branch || "").trim();
  const marks = Number.parseInt(body.marks, 10);
  if (!name || Number.isNaN(marks) || marks < 0 || marks > 100) return null;
  return { name, branch, marks };
}
const BAD = { error: "Name is required and marks must be 0 to 100." };

app.get("/api/students", handle(async (req, res) => {
  const search = "%" + (req.query.search || "") + "%";
  const result = await pool.query(
    "SELECT id, name, branch, marks FROM students WHERE name ILIKE $1 ORDER BY id",
    [search]);
  res.json(result.rows);
}));

app.get("/api/stats", handle(async (req, res) => {
  const result = await pool.query(
    `SELECT COUNT(*)::int AS total,
            ROUND(AVG(marks), 1)::float AS average,
            MAX(marks) AS highest
     FROM students`);
  res.json(result.rows[0]);
}));

app.post("/api/students", handle(async (req, res) => {
  const s = clean(req.body);
  if (!s) return res.status(400).json(BAD);
  const result = await pool.query(
    "INSERT INTO students (name, branch, marks) VALUES ($1, $2, $3) RETURNING *",
    [s.name, s.branch, s.marks]);
  res.status(201).json(result.rows[0]);
}));

app.put("/api/students/:id", handle(async (req, res) => {
  const s = clean(req.body);
  if (!s) return res.status(400).json(BAD);
  const result = await pool.query(
    "UPDATE students SET name = $1, branch = $2, marks = $3 WHERE id = $4",
    [s.name, s.branch, s.marks, Number(req.params.id)]);
  if (result.rowCount === 0) return res.status(404).json({ error: "Student not found" });
  res.json({ updated: true });
}));

app.delete("/api/students/:id", handle(async (req, res) => {
  const result = await pool.query("DELETE FROM students WHERE id = $1", [Number(req.params.id)]);
  if (result.rowCount === 0) return res.status(404).json({ error: "Student not found" });
  res.json({ deleted: true });
}));

const PORT = process.env.PORT || 3000;
app.listen(PORT, () => console.log("Open http://localhost:" + PORT));

Start it with node server.js and test the API before building any page: open http://localhost:3000/api/students in the browser. You should see your rows as JSON.

  • Status codes tell the browser what happened: 201 created, 400 bad input, 404 not found, 500 server error.
  • RETURNING * makes PostgreSQL send back the new row, including its generated id.
  • COUNT(*)::int converts the count to a normal number. Without it, pg returns counts as text.

Create public/app.js. It fetches data from the API, fills the table, and sends the form back:

const $ = id => document.getElementById(id);
let editingId = null;

async function api(url, options) {
  const res = await fetch(url, { headers: { "Content-Type": "application/json" }, ...options });
  const data = await res.json();
  if (!res.ok) throw new Error(data.error || "Something went wrong");
  return data;
}

function show(text) { $("msg").textContent = text; }

function cell(text) {
  const td = document.createElement("td");
  td.textContent = text ?? "";       // textContent keeps user text harmless
  return td;
}

function button(label, onclick) {
  const b = document.createElement("button");
  b.textContent = label;
  b.onclick = onclick;
  return b;
}

async function load() {
  const students = await api("/api/students?search=" + encodeURIComponent($("search").value));
  $("rows").replaceChildren();
  for (const s of students) {
    const tr = document.createElement("tr");
    tr.append(cell(s.id), cell(s.name), cell(s.branch), cell(s.marks));
    const actions = document.createElement("td");
    actions.append(button("Edit", () => startEdit(s)), button("Delete", () => remove(s)));
    tr.append(actions);
    $("rows").append(tr);
  }
  const st = await api("/api/stats");
  $("stats").textContent = `Students: ${st.total} | Average: ${st.average ?? 0} | Highest: ${st.highest ?? 0}`;
}

function startEdit(s) {
  editingId = s.id;
  $("name").value = s.name;
  $("branch").value = s.branch ?? "";
  $("marks").value = s.marks;
  $("save").textContent = "Save changes";
  $("cancel").hidden = false;
}

function resetForm() {
  editingId = null;
  $("form").reset();
  $("save").textContent = "Add student";
  $("cancel").hidden = true;
}

async function remove(s) {
  if (!confirm("Delete " + s.name + "?")) return;
  try {
    await api("/api/students/" + s.id, { method: "DELETE" });
    show("Student deleted");
    await load();
  } catch (err) { show(err.message); }
}

$("form").addEventListener("submit", async event => {
  event.preventDefault();                       // stop the page from reloading
  const body = JSON.stringify({
    name: $("name").value, branch: $("branch").value, marks: $("marks").value
  });
  try {
    if (editingId) await api("/api/students/" + editingId, { method: "PUT", body });
    else await api("/api/students", { method: "POST", body });
    show(editingId ? "Student updated" : "Student added");
    resetForm();
    await load();
  } catch (err) { show(err.message); }
});

$("cancel").onclick = resetForm;
$("search").addEventListener("input", () => load().catch(err => show(err.message)));
load().catch(err => show(err.message));

Restart the server, open http://localhost:3000, and try add, edit, delete and search. Keep pgAdmin open next to the browser so students see rows change.

Why textContent and not innerHTML? If a student types <script> as a name, innerHTML would run it (an attack called XSS). textContent shows it as plain text.

Lab network: other computers can open http://TEACHER-IP:3000 while your server runs. Use this only on a trusted network, since anyone can edit the data.

Check yourself

Students answer first, then click a question to see the answer.

1. Why can the browser not connect straight to PostgreSQL?

That would put the database password in the page for anyone to read. The server keeps the password and only returns the data the API allows.

2. What does await do?

It pauses that function until the database answers, while the rest of the server keeps working for other users.

3. Which HTTP method and SQL statement match “create a student”?

POST and INSERT.

4. Why does the server run clean() when the form already has required and min/max?

Browser checks can be skipped by anyone sending their own request. The server must always check input itself.

5. The total shows as "5" in quotes. What happened and how do you fix it?

PostgreSQL returns COUNT as a big number, which pg gives to JavaScript as text. Cast it in SQL: COUNT(*)::int.

Common errors

Message or problem Likely cause and fix
Cannot find module 'pg' Run npm install inside the project folder, and run node from that same folder.
password authentication failed Wrong PGPASSWORD or PGUSER in .env. Test the same login in psql.
ECONNREFUSED 127.0.0.1:5432 PostgreSQL is not running, or uses another port.
database "x" does not exist / relation "students" does not exist Wrong PGDATABASE, or Step 2 was not run.
Cannot GET / public/index.html is missing, or you started the server from a different folder.
Unexpected token '<' ... is not valid JSON The browser asked for a wrong API URL and got an HTML error page. Check the path in fetch.
Cannot read properties of undefined (reading 'name') The request body is empty. Check app.use(express.json()) and the Content-Type header.
EADDRINUSE :::3000 An old server is still running. Stop it with Ctrl+C or set PORT=3001.
Changes to server.js have no effect Restart the server, or run it with node --watch server.js.
A script never finishes Missing await pool.end() at the end of a test script.
Tip for teachers: let students test each API route in the browser address bar before writing the page. When the page fails, they can tell at once whether the problem is in the server or in the JavaScript.
