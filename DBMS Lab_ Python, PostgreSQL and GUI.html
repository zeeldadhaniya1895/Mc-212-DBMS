Python + PostgreSQL + GUI: a step-by-step lab

Students connect Python to the PostgreSQL database already running on their computer, run the four basic operations (create, read, update, delete), and wrap them in a desktop window. We build one small project: a Student Records app.

Before you start

Each student needs Python 3.9 or newer, a running PostgreSQL server, and a database they already created.

  1. Check Python: python --version.
  2. Make a folder named student_lab and keep every file inside it.
  3. Install the PostgreSQL driver: pip install psycopg2-binary. On Ubuntu also run sudo apt install python3-tk for the GUI toolkit. Tkinter already comes with Python on Windows and macOS.
  4. Write down your five connection details. You will need them in Step 1:
Detail Usual value Where to find it
host localhost Your own computer
port 5432 Default PostgreSQL port
dbname the name you created Left panel in pgAdmin, or \l in psql
user postgres The role you log in with
password set during installation The password you chose for that role

Quick check: open a terminal and run psql -U postgres -d your_dbname. If it asks for a password and lets you in, the server and database are fine, and any later problem is in your Python code.

Basics: how Python talks to PostgreSQL

Python uses a driver library, here psycopg2, to send SQL to the server and bring results back. Every program follows the same five moves:

Move Code Meaning
Connect conn = psycopg2.connect(...) Open a session with the server
Get a cursor cur = conn.cursor() The object that sends SQL and holds results
Execute cur.execute(sql, values) Run one SQL statement
Commit conn.commit() Save INSERT, UPDATE and DELETE changes permanently
Close conn.close() End the session

Remember: without commit() your changes are rolled back when the program ends. The code runs with no error, but the rows never appear in pgAdmin.

Step 1Connect to your database

Put the connection details in one file so every later program can reuse them. Create db_config.py and fill in your own values:

DB_SETTINGS = {
    "host": "localhost",
    "port": 5432,
    "dbname": "your_dbname",
    "user": "postgres",
    "password": "your_password",
}

Now create step1_connect.py to test the connection:

import psycopg2
from db_config import DB_SETTINGS

conn = psycopg2.connect(**DB_SETTINGS)
cur = conn.cursor()

cur.execute("SELECT version()")
print(cur.fetchone()[0])

cur.close()
conn.close()

Run it with python step1_connect.py. You should see your PostgreSQL version.

PostgreSQL 16.x on x86_64-pc-linux-gnu, compiled by ...

**DB_SETTINGS unpacks the dictionary into host=..., port=... keyword arguments. If this step fails, fix it before moving on. See the error table at the end.

Security: db_config.py holds a real password. Do not upload it to GitHub or share it in chat.

Step 2Create a table

Create step2_table.py. PostgreSQL uses SERIAL for an auto-numbering id.

import psycopg2
from db_config import DB_SETTINGS

conn = psycopg2.connect(**DB_SETTINGS)
cur = conn.cursor()

cur.execute("""
    CREATE TABLE IF NOT EXISTS students (
        id     SERIAL PRIMARY KEY,
        name   VARCHAR(100) NOT NULL,
        branch VARCHAR(50),
        marks  INTEGER
    )
""")

conn.commit()
cur.close()
conn.close()
print("Table ready")

Open pgAdmin, refresh your database, and look under Schemas > public > Tables. The students table should be there. Students can also check in psql with \dt.

Step 3Insert rows safely

Create step3_insert.py. Notice the %s placeholders. They are the same for every data type. Never join user input into the SQL text yourself, because that opens the door to SQL injection.

import psycopg2
from db_config import DB_SETTINGS

conn = psycopg2.connect(**DB_SETTINGS)
cur = conn.cursor()

cur.execute("INSERT INTO students (name, branch, marks) VALUES (%s, %s, %s)",
            ("Asha", "CSE", 82))

more = [("Ravi", "ECE", 74), ("Meena", "CSE", 91)]
cur.executemany("INSERT INTO students (name, branch, marks) VALUES (%s, %s, %s)", more)

conn.commit()
cur.close()
conn.close()
print("Rows added")

Bad: f"INSERT ... VALUES ('{name}')" lets a user type SQL into your program. Good: %s placeholders with a tuple of values. Use %s even for numbers.

Step 4Read data with SELECT

import psycopg2
from db_config import DB_SETTINGS

conn = psycopg2.connect(**DB_SETTINGS)
cur = conn.cursor()

cur.execute("SELECT id, name, branch, marks FROM students ORDER BY id")
for row in cur.fetchall():
    print(row)

print("--- CSE students with marks above 80 ---")
cur.execute("SELECT name, marks FROM students WHERE branch = %s AND marks > %s",
            ("CSE", 80))
print(cur.fetchall())

cur.close()
conn.close()
(1, 'Asha', 'CSE', 82) (2, 'Ravi', 'ECE', 74) (3, 'Meena', 'CSE', 91) --- CSE students with marks above 80 --- [('Asha', 82), ('Meena', 91)]

fetchall() returns a list of tuples. Use fetchone() for a single row. SELECT does not change data, so it needs no commit.

Step 5Update and delete

import psycopg2
from db_config import DB_SETTINGS

conn = psycopg2.connect(**DB_SETTINGS)
cur = conn.cursor()

cur.execute("UPDATE students SET marks = %s WHERE name = %s", (88, "Ravi"))
print("Rows updated:", cur.rowcount)

cur.execute("DELETE FROM students WHERE id = %s", (3,))
print("Rows deleted:", cur.rowcount)

conn.commit()
cur.close()
conn.close()

Lab check: always include a WHERE clause. An UPDATE or DELETE without one changes every row. Use cur.rowcount to confirm how many rows were affected. A single value in a tuple needs a trailing comma: (3,).

Step 6Your first Tkinter window

A GUI is a window with widgets (labels, text boxes, buttons) and a loop that waits for clicks. Create step6_gui.py:

import tkinter as tk
from tkinter import messagebox

def say_hello():
    messagebox.showinfo("Greeting", "Hello, " + name_entry.get())

root = tk.Tk()
root.title("My first GUI")
root.geometry("300x150")

tk.Label(root, text="Your name:").pack(pady=5)
name_entry = tk.Entry(root)
name_entry.pack()
tk.Button(root, text="Greet", command=say_hello).pack(pady=10)

root.mainloop()
Widget Use
Label Show fixed text
Entry One-line text box; read with .get()
Button Runs the function given in command=
ttk.Treeview Table that displays database rows

mainloop() keeps the window open and listens for events. Code after it runs only when the window closes.

Step 7Put it together: Student Records app

This app has input boxes, Add, Update and Delete buttons, and a table that refreshes after each action. Save it as app.py in the same folder as db_config.py.

import psycopg2
import tkinter as tk
from tkinter import ttk, messagebox
from db_config import DB_SETTINGS

def run(sql, params=(), fetch=False):
    """Connect, run one statement, commit, close. Returns rows if fetch=True."""
    conn = psycopg2.connect(**DB_SETTINGS)
    try:
        cur = conn.cursor()
        cur.execute(sql, params)
        rows = cur.fetchall() if fetch else None
        conn.commit()
        return rows
    except Exception:
        conn.rollback()
        raise
    finally:
        conn.close()

def refresh():
    table.delete(*table.get_children())
    for row in run("SELECT id, name, branch, marks FROM students ORDER BY id", fetch=True):
        table.insert("", "end", values=row)

def clear_form():
    for var in (name_var, branch_var, marks_var):
        var.set("")

def read_form():
    """Return (name, branch, marks) or None if the input is invalid."""
    if not name_var.get().strip():
        messagebox.showwarning("Missing data", "Name is required.")
        return None
    try:
        marks = int(marks_var.get())
    except ValueError:
        messagebox.showerror("Invalid marks", "Marks must be a whole number.")
        return None
    return name_var.get().strip(), branch_var.get().strip(), marks

def selected_id():
    chosen = table.selection()
    if not chosen:
        messagebox.showinfo("Select a row", "Click a student in the table first.")
        return None
    return table.item(chosen[0])["values"][0]

def add():
    data = read_form()
    if data:
        run("INSERT INTO students (name, branch, marks) VALUES (%s, %s, %s)", data)
        clear_form()
        refresh()

def update():
    sid, data = selected_id(), read_form()
    if sid and data:
        run("UPDATE students SET name=%s, branch=%s, marks=%s WHERE id=%s", data + (sid,))
        refresh()

def delete():
    sid = selected_id()
    if sid and messagebox.askyesno("Confirm", "Delete this student?"):
        run("DELETE FROM students WHERE id=%s", (sid,))
        clear_form()
        refresh()

def on_select(event):
    chosen = table.selection()
    if chosen:
        _, n, b, m = table.item(chosen[0])["values"]
        name_var.set(n); branch_var.set(b); marks_var.set(m)

root = tk.Tk()
root.title("Student Records")
name_var, branch_var, marks_var = tk.StringVar(), tk.StringVar(), tk.StringVar()

form = ttk.Frame(root, padding=10)
form.pack(fill="x")
for i, (label, var) in enumerate([("Name", name_var), ("Branch", branch_var), ("Marks", marks_var)]):
    ttk.Label(form, text=label).grid(row=0, column=i * 2, padx=4)
    ttk.Entry(form, textvariable=var, width=14).grid(row=0, column=i * 2 + 1, padx=4)

buttons = ttk.Frame(root, padding=(10, 0))
buttons.pack(fill="x")
ttk.Button(buttons, text="Add", command=add).pack(side="left", padx=4)
ttk.Button(buttons, text="Update", command=update).pack(side="left", padx=4)
ttk.Button(buttons, text="Delete", command=delete).pack(side="left", padx=4)

cols = ("id", "name", "branch", "marks")
table = ttk.Treeview(root, columns=cols, show="headings", height=10)
for col in cols:
    table.heading(col, text=col.title())
    table.column(col, width=90)
table.pack(padx=10, pady=10, fill="both", expand=True)
table.bind("<<TreeviewSelect>>", on_select)

try:
    refresh()
except psycopg2.Error as e:
    messagebox.showerror("Database error", str(e))

root.mainloop()

How the pieces connect

  • run() is the only function that touches the database. It rolls back on error, so one failed statement never blocks the next one.
  • Each button calls a function. The function validates input, runs SQL, then calls refresh() so the table always matches the database.
  • StringVar links a text box to a Python variable, so you can read and set its text easily.
  • Open pgAdmin while the app runs and refresh the table view. Students see their clicks change real data.

Practice tasks and common errors

Tasks for students

  1. Add a Search box that filters the table by name using ILIKE %s with "%" + text + "%" (ILIKE ignores upper and lower case in PostgreSQL).
  2. Add an email column with ALTER TABLE students ADD COLUMN email VARCHAR(100) and show it in the form and table.
  3. Show the average marks per branch in a label, using GROUP BY.
  4. Build your own project (Library, Hospital or Inventory) with two related tables, a foreign key and a JOIN query.

Common errors

Message Likely cause and fix
ModuleNotFoundError: psycopg2 Driver not installed. Run pip install psycopg2-binary, using the same Python you run the file with.
password authentication failed for user Wrong password or user in db_config.py. Test the same login in psql.
connection refused (port 5432) PostgreSQL server is not running, or it uses a different port. Start the service and check the port in pgAdmin server properties.
database "x" does not exist The dbname is misspelled. List real names with \l in psql.
relation "students" does not exist Table not created yet, or you are connected to a different database. Run Step 2 again.
current transaction is aborted An earlier statement failed and the connection was reused. Call conn.rollback() after errors, as run() does.
Rows missing in pgAdmin You forgot conn.commit().
No module named tkinter On Linux run sudo apt install python3-tk.
Tip for teachers: let students type every program themselves instead of copying. The errors they hit teach more than the code does.
